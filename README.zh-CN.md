# TimeCue

[English](README.md) | [简体中文](README.zh-CN.md)

会报时的训练计时器，让你专注动作，无需频繁看屏幕。适合跳绳、悬挂、平板支撑、拉伸等按时长进行的活动。当前版本使用英文界面与英文语音。

**在线使用：** https://omegazhang3.github.io/voice-timer/

## 功能亮点

- **定时语音报时**：按预设或自定义间隔播报已用时。简洁模式只报秒数，例如“5 seconds”“10 seconds”。
- **准备倒计时**：支持 3、5、10 秒语音倒计时，也可关闭，方便先准备好姿势；默认 3 秒。
- **灵活控制计时**：支持开始、暂停、继续和停止，准备倒计时与暂停时间不计入训练时长。
- **分组训练记录**：为 Session 命名，如“跳绳”“悬挂”，每段停止后的计时可手动保存为一组 Set。
- **快速修正时长**：减少时跳到前一个 5 秒整倍数，例如 47→45→40；增加时每次加 1 秒，最高不超过实测时长。
- **训练汇总**：查看已保存的组数、每组时长及累计训练时间。
- **轻量易用**：手机或电脑浏览器直接打开，无需安装或注册。训练记录仅保留在当前页面，刷新后清空；计时偏好单独保存。

## 计时与语音选项

- 正向累计计时，使用英文播报，例如“1 minute 30 seconds elapsed”。
- 报时间隔预设为 5、10、30、60 秒，也可自定义为 5 至 3,600 秒之间的整数。
- **Short announcements** 开启简洁播报，只报累计秒数，例如“5 seconds”“10 seconds”“65 seconds”，不加“elapsed”。可随时切换；**Test voice** 按当前模式与间隔试听语音。
- 支持开始、暂停、继续和停止；停止后的时长保持显示，直到再次开始或离开、刷新页面。
- **Start delay** 可选 Off、3、5、10 秒，默认 3 秒。每次新计时开始前显示大字倒计时并语音播报，以“Go!”提示正式开始。可随时取消准备倒计时；准备时间不计入已用时，也不计入报时间隔。暂停后继续不会再次倒计时。
- 暂停时间不计入已用时。计时过程中报时间隔设置会锁定。
- 可在开始前试听语音；关闭准备倒计时后直接开始，以及暂停后继续时，会播放简短语音确认。
- 浏览器保存报时间隔、准备倒计时和播报模式偏好，无需账户或后端服务。
- 页面适配手机与电脑屏幕。

## Session 与 Set

Session 表示一次训练，Set 表示其中一组计时。可以手动创建并命名 Session，名称支持中文；也可直接开始计时，应用会使用已填写的名称或当前日期时间自动创建 Session。每组停止后，可先用 **Set duration** 的 **− / +1** 按钮调整时长，再点击 **Save set** 保存。例如，实测 20 秒可减少为 15 秒，再逐秒加回 20 秒，但不能超过 20 秒。原始实测时长仍会显示，Session 统计使用调整后的保存值。未保存的时长不计入总时间，同一组不能重复保存。

点击 **Next set** 可沿用当前报时与准备倒计时设置开始下一组。如果还有未保存的 Set，开始下一组或结束 Session 时，会提示保存、丢弃或继续编辑。Session 进行期间，可通过 **Delete** 删除已保存的组。

停止计时后，点击 **Finish session** 查看每组记录、总组数和累计时长。Set 时长默认为计时器显示的完整秒数。减少按钮跳到前一个 5 秒整倍数，例如 47→45→40、41→40；增加按钮每次加 1 秒，最多恢复至原始实测时长。如果下一步会超过实测时长或低于 1 秒，对应按钮会禁用。实测 5 秒及以下的组保持原始时长，不足 1 秒的计时不生成待保存记录。准备倒计时、暂停、组间休息和丢弃的组不计入累计时长。

Session 数据仅保存在当前页面内存中，不写入历史数据库或浏览器本地存储，也不上传服务器。刷新或关闭页面会清空 Session。应用会请求浏览器在离开页面前提示，但部分手机浏览器可能不显示提示。如果当前有已保存记录，新建 Session 前需要确认，之后会清除上一轮汇总。计时偏好不受影响，仍单独保存。

## 本地运行

在项目目录启动静态 HTTP 服务，例如：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 http://localhost:8000。应用使用 JavaScript 模块，请通过 HTTP/HTTPS 访问，不要直接打开 `index.html`。本地运行无需安装依赖或构建。

## 测试

使用 Node.js 20 或更新版本：

```sh
npm test
```

测试覆盖报时间隔边界、暂停与继续、延迟更新、停止与重新开始、准备倒计时与取消、输入校验、英文时长格式，以及旧模块被缓存时能否加载正确的语音格式化模块。

## GitHub Pages 部署

每次推送到 `main` 分支，`.github/workflows/pages.yml` 工作流都会运行测试，并执行 `npm run build` 构建静态站点。仓库 Settings → Pages → Source 需设为 **GitHub Actions**。

构建会在 `dist/` 中为 JavaScript、CSS 和图标生成包含内容哈希的文件名。应用会导入版本匹配的计时模块，避免新界面使用缓存中的旧语音格式化逻辑。本地开发仍可直接通过静态服务器运行源文件。

## 语音与计时说明

语音使用浏览器 Web Speech API 和设备提供的英文语音。可用声音、音质及是否需要联网取决于浏览器与语音服务提供方。应用不请求麦克风权限。如果语音不可用，页面会说明原因，计时器仍可使用。

已用时根据单调时钟的时间差计算，不依赖回调次数累加。页面延迟更新时，只播报一次当前已用时，不补播错过的报时。暂停或停止会取消语音。

第一版专注前台计时，暂不包含后台或锁屏报时、保持屏幕常亮、PWA 安装和语音指令。刷新或关闭页面会结束当前 Session；仅报时间隔、准备倒计时和播报模式偏好会持久保存。
